# Sales Analysis Dashboard | Power BI

## 📊 Overview
This project presents an interactive sales dashboard built using Power BI to analyze sales performance, profitability, products, categories, and regional performance.

![Sales Dashboard](dashboard.png)

## 🔍 Key Insights
- Total Sales: **161.65K**
- Total Profit: **18.55K**
- The **East** region generated the highest sales with approximately **106K**.
- **Technology** was the leading category, contributing approximately **65.57%** of total sales.
- **Laptop** was the highest-selling product.

## 📈 Dashboard Features
- Total Sales and Total Profit KPIs
- Sales analysis by Region
- Sales analysis by Product
- Sales analysis by Category
- Interactive Region and Product filters

## 🛠 Tools Used
- Power BI
- Data Cleaning
- Data Analysis
- Data Visualization
